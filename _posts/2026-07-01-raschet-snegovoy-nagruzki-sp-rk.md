Снеговая нагрузка — одна из двух климатических нагрузок, которые собираются для любого
здания в Казахстане. Ниже — полная методика по СП РК EN 1991-1-3: от характеристического
значения на грунте до расчётной нагрузки на кровлю.

## Основная формула

Снеговая нагрузка на кровлю для постоянной/переходной расчётной ситуации:

**s = μ · Ce · Ct · sk**

где **sk** — характеристическое значение на грунте, кПа (по карте снегового районирования
РК, карта 4 национального приложения); **μ** — коэффициент формы кровли; **Ce** —
коэффициент окружающей среды; **Ct** — термический коэффициент (для обычных кровель 1,0).

## Коэффициент формы μ: где ошибаются

Для одно- и двускатных кровель базовый коэффициент μ₁ зависит от уклона α:

| Уклон α | μ₁ |
|---|---|
| 0° ≤ α ≤ 30° | 0,8 |
| 30° < α < 60° | 0,8·(60 − α)/30 |
| α ≥ 60° | 0 |

Типовая ошибка — посчитать двускатную кровлю только на равномерное загружение. Норма
требует рассмотреть **три схемы**: (i) снег на обоих скатах полностью, (ii) и (iii) —
половина снега на одном скате при полном на другом. Для неразрезных прогонов и рам
именно несимметричная схема часто даёт расчётный случай.

## Пошаговый пример

Двускатная кровля, уклон α = 25°, обычная местность. Примем **sk = 1,0 кПа** — условное
значение для примера; для своей площадки возьмите sk по карте 4.

1. Уклон 25° ≤ 30° → μ₁ = 0,8.
2. Обычная местность → Ce = 1,0; обычная кровля → Ct = 1,0.
3. Схема (i), оба ската: s = 0,8 · 1,0 · 1,0 · 1,0 = **0,80 кПа**.
4. Схема (ii): левый скат 0,40 кПа, правый — 0,80 кПа. Схема (iii) — зеркально.
5. Расчётное значение для ULS: s_d = 1,5 · 0,80 = **1,20 кПа**.

Все три схемы прикладываются к модели как отдельные загружения — расчётный комплекс сам
переберёт их в сочетаниях. Коэффициенты сочетаний для снега при H ≤ 1000 м:
ψ₀ = 0,5; ψ₁ = 0,2; ψ₂ = 0.

## Локальные эффекты, которые нельзя пропускать

- **Перепад высот** — у стены более высокого здания снег наметается, μ у стены кратно выше базового;
- **Заграждения и парапеты** — скопление с треугольной эпюрой;
- **Нависание на краю кровли** — дополнительная погонная нагрузка на карниз;
- **Многопролётные кровли** — повышенный снег в ендове;
- **Чрезвычайная снеговая нагрузка sAd = 2·sk** — отдельная аварийная расчётная ситуация, входит в сочетание без γf.
