Сбор ветровой нагрузки по Еврокоду заметно отличается от привычного СНиП: вместо
нормативного давления по районам — базовая скорость ветра, профиль по высоте и
аэродинамические коэффициенты по зонам поверхности.

## Цепочка расчёта

**vb → vm(z) → qp(z) → we = qp(ze) · cpe**

### Шаг 1. Базовая скорость ветра vb

По карте ветрового районирования РК: vb = c_dir · c_season · vb,0. Для большинства задач
оба коэффициента равны 1,0.

### Шаг 2. Средняя скорость vm(z) и категория местности

Профиль зависит от шероховатости: vm(z) = cr(z) · co(z) · vb. Коэффициент cr(z) считается
через логарифм z/z0, где z0 — параметр категории местности (от открытого моря 0 до плотной
городской застройки IV). Выбор категории — самое частое место споров с экспертизой.

### Шаг 3. Пиковое давление qp(z)

Учитывает пульсации через интенсивность турбулентности Iv(z):

**qp(z) = [1 + 7·Iv(z)] · ½ · ρ · vm²(z)**, где ρ = 1,25 кг/м³.

### Шаг 4. Коэффициенты cpe и давление по зонам

Стены делятся на зоны A–E, кровля — на свои зоны (для плоской F, G, H, I). Для каждой:
**we = qp(ze) · cpe**. Знак важен: на кровле почти всегда отсос, и для лёгких кровель
именно он определяет крепёж. Полное воздействие — с учётом внутреннего давления:
w = qp·(cpe − cpi).

## Что часто упускают

- **Второе направление ветра** — зоны и коэффициенты для X и Y разные, считать оба;
- **Зависимость cpe от h/d** — коэффициенты меняются с пропорциями здания;
- **Внутреннее давление cpi** — для зданий с проёмами может решать для крепежа ограждения;
- **Коэффициенты сочетаний для ветра**: ψ₀ = 0,6; ψ₁ = 0,2; ψ₂ = 0.
