Расчёт снеговой нагрузки по СП РК EN 1991-1-3: пошаговый пример

СП РК EN 1991-1-3:2003/2011 · для инженеров-расчётчиков · читать ~7 минут

Снеговая нагрузка — одна из двух климатических нагрузок, которые собираются для любого здания в Казахстане. В этой статье — полная методика по СП РК EN 1991-1-3 (казахстанская адаптация Еврокода 1, часть 1-3): от характеристического значения на грунте до расчётной нагрузки на кровлю, с разбором коэффициента формы и снегового мешка.

Основная формула

Снеговая нагрузка на кровлю для постоянной/переходной расчётной ситуации:

s = μi · Ce · Ct · sk

где:

  • sk — характеристическое значение снеговой нагрузки на грунте, кПа. Определяется по карте снегового районирования РК (карта 4 в национальном приложении) для площадки строительства;
  • μi — коэффициент формы кровли. Зависит от уклона и конфигурации — именно здесь чаще всего ошибаются;
  • Ce — коэффициент окружающей среды (открытая местность, обычная, защищённая);
  • Ct — термический коэффициент. Для обычных кровель Ct = 1,0; снижение допускается только для кровель с высокой теплопередачей при обосновании.

Коэффициент формы μ: где ошибаются

Для одно- и двускатных кровель базовый коэффициент μ1 зависит от уклона α:

Уклон αμ1
0° ≤ α ≤ 30°0,8
30° < α < 60°0,8·(60 − α)/30
α ≥ 60°0

Типовая ошибка — посчитать двускатную кровлю только на равномерное загружение. Норма требует рассмотреть три схемы: (i) снег на обоих скатах полностью, (ii) и (iii) — половина снега на одном скате при полном на другом (несимметричные схемы, «снеговой мешок»). Для неразрезных прогонов и рам именно несимметричная схема часто даёт расчётный случай, хотя суммарная нагрузка в ней меньше.

Пошаговый пример

Двускатная кровля, уклон α = 25°, обычная местность, обычный тепловой режим. Характеристическое значение на грунте примем sk = 1,0 кПа — условное значение для примера; для своей площадки возьмите sk по карте 4 для вашего снегового района.

  1. Уклон 25° ≤ 30° → μ1 = 0,8.
  2. Обычная местность → Ce = 1,0; обычная кровля → Ct = 1,0.
  3. Схема (i), оба ската: s = 0,8 · 1,0 · 1,0 · 1,0 = 0,80 кПа на каждом скате.
  4. Схема (ii): левый скат 0,5·μ1·sk = 0,40 кПа, правый — 0,80 кПа. Схема (iii) — зеркально.
  5. Расчётное значение для ULS: sd = γf · s = 1,5 · 0,80 = 1,20 кПа.
Все три схемы прикладываются к расчётной модели как отдельные загружения — расчётный комплекс (ЛИРА, SCAD) сам переберёт их в сочетаниях. Коэффициенты сочетаний для снега при высоте площадки H ≤ 1000 м: ψ0 = 0,5; ψ1 = 0,2; ψ2 = 0.

Локальные эффекты, которые нельзя пропускать

  • Перепад высот. У стены более высокого здания снег наметается — коэффициент μ у стены может кратно превышать базовый, зона наноса имеет длину ls;
  • Заграждения и парапеты. За препятствием образуется скопление с треугольной эпюрой;
  • Нависание на краю кровли — дополнительная погонная нагрузка se на карниз (важно для лёгких карнизов);
  • Многопролётные кровли — повышенный снег в ендове;
  • Чрезвычайная снеговая нагрузка sAd — для районов, где норма этого требует, отдельная аварийная расчётная ситуация (sAd = 2·sk, входит в сочетание без γf).
