Ветровая нагрузка по СП РК EN 1991-1-4: методика от vb до давления по зонам

СП РК EN 1991-1-4:2005/2011 · для инженеров-расчётчиков · читать ~6 минут

Сбор ветровой нагрузки по Еврокоду заметно отличается от привычного СНиП: вместо нормативного давления по районам — базовая скорость ветра, логарифмический профиль по высоте и аэродинамические коэффициенты по зонам поверхности. Разберём цепочку расчёта по СП РК EN 1991-1-4 целиком.

Цепочка расчёта

vb → vm(z) → qp(z) → we = qp(ze) · cpe

Шаг 1. Базовая скорость ветра vb

Определяется по карте ветрового районирования РК для площадки строительства: vb = cdir · cseason · vb,0. Для большинства задач направленный и сезонный коэффициенты равны 1,0, и vb = vb,0 вашей ветровой зоны.

Шаг 2. Средняя скорость vm(z) и категория местности

Профиль скорости по высоте зависит от шероховатости: vm(z) = cr(z) · co(z) · vb. Коэффициент шероховатости cr(z) считается через логарифм от z/z0, где z0 — параметр шероховатости категории местности (от открытого моря 0 до плотной городской застройки IV). Выбор категории — самое частое место споров с экспертизой: занизишь категорию — перезаложишься, завысишь — не защитишь.

Шаг 3. Пиковое давление qp(z)

Учитывает пульсации через интенсивность турбулентности Iv(z):

qp(z) = [1 + 7·Iv(z)] · ½ · ρ · vm²(z)

где ρ = 1,25 кг/м³ — плотность воздуха. Это давление — общее для всех поверхностей здания на данной высоте; дальше оно распределяется по зонам коэффициентами.

Шаг 4. Аэродинамические коэффициенты cpe и давление по зонам

Стены делятся на зоны A–E (наветренная D, заветренная E, боковые A–C), кровля — на свои зоны (для плоской F, G, H, I) в зависимости от формы. Для каждой зоны:

we = qp(ze) · cpe

Знак важен: положительное давление — на поверхность, отрицательное — отсос. На кровле почти всегда отсос, и для лёгких кровель именно он определяет крепёж. Полное воздействие — с учётом внутреннего давления cpi: w = qp·(cpe − cpi).

Что часто упускают

  • Второе направление ветра. Здание обдувается и вдоль, и поперёк — зоны и коэффициенты для направлений X и Y разные, считать нужно оба;
  • Зависимость cpe от отношения h/d — для одних и тех же зон коэффициенты меняются с пропорциями здания;
  • Внутреннее давление cpi — для зданий с проёмами добавляет к отсосу и может решать для крепежа ограждения;
  • Коэффициенты сочетаний для ветра: ψ0 = 0,6; ψ1 = 0,2; ψ2 = 0.
